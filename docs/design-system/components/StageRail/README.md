# StageRail

The three stages as numbered steps with arrows between them: a toggle you can flip back and forth, that still shows the direction things go.

`.rail` of `.step`s separated by chevrons. Each step is a number in a circle and the stage name. The current one is an `ink` pill with `on-ink` text, the only dark thing in the top bar. The others look the same as each other: every stage is always one click away, and none is ever "done".

Hover shows the purpose in a tooltip: Spill "get it all out", Shape "give it an order", Draft "write it".

**Don't** add counts, checkmarks or progress. Where you are is enough.
