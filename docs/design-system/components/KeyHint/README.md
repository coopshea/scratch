# KeyHint

A key, drawn as a small keycap. Shortcuts are learned by seeing them where the action is.

`.kbd`: `text-kbd` (IBM Plex Mono 11px) on `card`, a `line-strong` border with a 2px bottom edge, `radius-tag`. Inside a primary button it goes translucent on the ink. Use inside the button it triggers (`cut into ideas ⌘↵`), in menus (the slash menu), and in a note's empty line (`Type / for blocks`).
