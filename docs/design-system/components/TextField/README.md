# TextField

A labelled box to type into, for settings and money. The writing surfaces stay borderless.

`.field`: `field-label` above, a 40px `.input` (`card`, `edge` border), help below in `text-small`. Focus: a 2px `focus` ring. Invalid: `objection` border and the help line saying the fix. Saved secrets show as a status line ("Connected"), never as placeholder text. `.input-row` puts the field's own button beside it; `.input-money` prefixes `$`.
