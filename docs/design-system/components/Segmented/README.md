# Segmented

Two to five options where exactly one is on: which outline you're shaping into, once or monthly.

`.seg`: options on a `desk` track; the chosen one is a `card` with `shadow-card`, lifted out of the tray. 30px options at 13px.

**The consumer provides** the options, the chosen one and a change handler. `role="tablist"` when it switches a view, a radio group when it sets a value. More than five: use a menu.
