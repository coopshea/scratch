# TypeTag

What kind of idea this is: a small capitalised word with a mark.

`.tag` in `text-tag` with a 6px mark. Claims `ink` (square), questions `question` (open ring), objections `objection` (diamond), the rest `ink-3` (dot). The mark's shape differs as well as its colour. Only questions and objections get their own colour; a group's point card drops the tag.
