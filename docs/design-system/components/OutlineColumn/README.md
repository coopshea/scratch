# OutlineColumn

Your outline at the left of Draft: each level once, with its ideas as tiles you can still drag into a new order, before or while you write.

`.outline-col` on `desk`, `width-outline`. Each level is an `.osec` with its name in `text-label`; each idea a `.tile` (grip handle plus a compact `IdeaCard`). The level you're writing in gets `pencil-soft` and a 3px `pencil` rule. An idea you've written about is crossed off (`.is-crossed`, a `go` check).

**Reordering** tiles here reorders the plan; what that does to the text depends on the Draft approach being tested (see the Draft screens). Level names appear only here; the editor has plain dividers.

**Crossing off** starts with the local keyword match the code already has (free, instant); matching paraphrases needs a small local model later.
