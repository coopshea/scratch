# IdeaSheet

Everything about one idea, in a panel at the right: type, label, your words, and a note.

`.sheet`: `page`, `line` left border, `width-sheet`. Top: the type as a `TypeTag` menu, `Move to` (any group in Spill, any level in Shape: the keyboard path for every drag), `Cut`, close. The label in `text-heading`, edited in place. **Your words**: the verbatim cut as `text-quote` behind a rule. **Note**: `NoteBlocks`.

Opens when you select an idea; Esc closes it; selecting never moves the board. "Cut" rather than "Delete": cut ideas stay in History.
