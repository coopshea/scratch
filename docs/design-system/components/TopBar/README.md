# TopBar

One bar, three zones: the document on the left, the stages in the middle, you on the right.

`.topbar`: 56px on `page`, a `line` hairline under it. Left: the documents button and the title in `text-title` serif (it's the writer's), `Name this piece` in italic `ink-3` until named. Centre: the `StageRail`. Right: the `CreditsMeter`, History, Export (Draft only), the avatar. The side zones are equal widths so the rail sits in the true centre.

**Don't** put errors here; they go where they happened. No logo.
