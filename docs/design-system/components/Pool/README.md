# Pool

Shape's right half: every group you haven't placed yet, in two masonry columns, the same trays as Spill.

`.pool` on `desk` with one title, `Ideas`, and `.pool-cols`: two columns, each tray into the shorter one (`masonry` in `src/cards.ts`). Drag a tray left onto a `Lane` to place it; drag it back to take it out. Loose ideas sit muted at the bottom.

**Don't** add commentary ("not in the outline", "stays out"). Left here means left out; that's clear from where it is.
