# NoteBlocks

Notes as blocks you can drag into a new order, with `/` for everything else: BlockNote, which the app already uses for notes, restyled to the system.

Each block shows a `+` and a grip at its left edge on hover; drag the grip to move the block. Typing `/` opens the slash menu: a `card` with `shadow-lift`, grouped items (icon tile, name, one-line hint), the active one on `wash`, arrow keys and Enter to pick. An empty line says "Type / for blocks".

**Commands**
- Basic (BlockNote's own): Text, Heading, Bullet list, To-do, Quote, Image.
- Scratch's own: **Gap** (inserts `[ ]`, something to find out later; the review pass can fill it from Readwise), **From Readwise** (search your highlights, insert one as a quote with its source), **Link an idea** (points to another idea by its label).

Use the same editor anywhere a writer writes more than a line: idea notes now; possibly the draft (see the Draft screens). Writer's text in blocks is serif.
