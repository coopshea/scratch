# CreditsMeter

How many credits are left, always in the top bar, so running out is never a surprise. It links to the account page.

`.meter`: a `desk` pill in `text-small` at 500. Free: `2 free credits`. Paid: `38 credits`. On the writer's own key: `Your key`. Owners: hidden. `.is-low` (5 or fewer) in `question`; `.is-out` in `objection`.

Each run of Spill uses about 1 credit; a long spill can use 2 or 3. Paying $5 buys credits, never "$4.55 of balance": the card fee is priced into the credit, and explained only on the account page.
